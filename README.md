# One-Sentence Absurd Invention Pitch

`entry.txt` holds one 82-character sentence about a pen that resigns when it runs dry mid-word.
`python3 main.py` writes those exact bytes to `/output/entry.txt`; `python3 main.py --check` reads them back.
Deterministic, offline, Python 3 standard library only.
`research.md` records the 24-candidate scoring, the judge-seat critique and the gate check.
